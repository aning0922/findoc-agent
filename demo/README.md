# 静态历史演示

无需模型密钥或业务数据库，运行：

```bash
python3 demo/serve.py --port 14406
```

打开 <http://127.0.0.1:14406/projects/findoc/>。建议路线：作品介绍 → 美的跨年研究 → A10 原表问答 → 报告 v2 → 版本比较 → 指定 v1 下载。

`site/` 是既有经筛选的静态作品模块，包含 22 个公开响应文件和 2 个托管配置文件。`artifact-manifest.json` 保留逐文件大小与 SHA-256；服务启动时核验完整清单，只从内存白名单响应 GET/HEAD。不会提供目录浏览、API 代理、业务写入或模型调用。

内容属于历史研究：原财务数值、证据、语义待审状态和用户编辑说明保留。下载的是固定历史 Markdown，不授予当前来源或事实资格。原始 PDF、数据库和内部 trace 不在包中。

服务仅监听本机，退出按 Ctrl+C。此仓库公开源码和演示资产，不代表已部署公网网站。

# 本地静态演示

这个入口用于快速了解产品：阅读已保存的财务研究、原文问答和报告版本，无需模型凭据或业务数据库。需要上传资料、提出新问题或执行研究时，请启动 [README 中的完整工作台](../README.md#快速开始)。

## 启动

克隆仓库后，在项目根目录使用 Python 3.11+ 执行：

```bash
python3 demo/serve.py --port 14406
```

打开 [http://127.0.0.1:14406/projects/findoc/](http://127.0.0.1:14406/projects/findoc/)。服务只监听本机，结束时按 Ctrl+C；端口被占用时，可通过 `--port` 换用其他端口。

## 建议浏览路线

1. **作品介绍**：了解应用目标与主要能力。
2. **美的跨年研究**：查看三项指标的原值、差额与变化率。
3. **A10 原表问答**：查看原文摘录、年度列和来源。
4. **报告 v2**：阅读研究摘要、证据与待审说明。
5. **版本比较与下载**：比较 v1/v2，下载指定版本的 Markdown。

演示内容来自筛选后的历史研究，保留原始金额、引用、用户编辑和人工审阅状态。页面操作只用于阅读和下载，不会重新提问、调用模型或写入业务数据。

部分 PDF 链接指向公开披露网站；历史 Markdown 中的应用内链接则需要对应 FinDoc 服务和原文件。演示不包含完整年报 PDF。

## 文件与验证

`site/` 包含 22 个可访问文件和 2 个托管配置文件。启动程序按 [artifact-manifest.json](artifact-manifest.json) 核对文件大小和 SHA-256，并仅提供清单允许的 GET/HEAD 响应；托管配置文件不由该服务对外返回。

这些文件与已审核版本保持相同字节。若文件缺失、被修改或清单不匹配，服务会拒绝启动；应检查对应文件和版本，不通过删除校验来继续运行。

本目录提供本地预览与静态资产，仓库公开不代表另有在线演示站点。工作台截图和历史验证范围见[项目状态](../docs/project-status.md)。

# 项目状态与界面

FinDoc Agent 当前面向本地单人财报研究。产品界面使用 FinDoc Analyst 名称，公开仓库使用 FinDoc Agent；两者对应同一套应用代码。

## 当前实现

| 能力 | 当前范围 |
| --- | --- |
| 资料管理 | 企业创建、年报上传、年度与会计口径绑定、处理状态和来源纠错。 |
| 财务分析 | 营业收入、归母净利润、经营活动现金流量净额；人工核对后保存事实，进行跨年或同期比较。 |
| 原文问答 | 在选定报告中检索并呈现经校验的原文摘录，保存引用和问答记录。 |
| 经营研究 | 两类固定模板、人工等待与继续、财务分析、经营原文和模型解释。 |
| 研究报告 | 从完成的经营研究生成草稿，编辑标题与结论，保存版本并导出 Markdown。 |

| 检查 | 初始发布记录 |
| --- | --- |

| 前端单元测试 | 183 项通过；25 项依赖私有历史原件的测试明确跳过。 |
| 受控浏览器回归 | 2 项通过，覆盖 Agent 回答、拒答和刷新读取。 |
| 前端构建与 lint | 通过；lint 保留 1 条已有的 Fast Refresh 警告。 |
| 静态演示 | 22 个响应文件通过大小与 SHA-256 核对。 |

这些数字来自初始发布的 [source-snapshot.json](source-snapshot.json)，不是对后续提交的固定承诺。[GitHub Actions](https://github.com/aning0922/findoc-agent/actions/workflows/quality.yml) 提供各提交的实际结果。测试替身用于验证交互和数据处理，不用于评估真实模型的回答质量。

### 历史真实流程验证

公开版之前的交付记录包含：四份真实年报、十二项由项目维护者核对并接受的财务事实、三项真实经营研究、三份报告的六个版本，以及指定版本下载和重启读取。

这些是特定资料与配置下的历史验证，不作为通用准确率。原运行数据库和内部验收附件保留在私有归档；新问答与经营解释仍有人工语义审阅待完成。公开源码可用于重新执行流程，历史实例则通过截图和已筛选的静态演示展示。

## 当前限制

- **资料适配**：主要覆盖已验证的中文文本层年报版式；扫描件 OCR 和任意复杂表格尚不在支持范围内。
- **检索与解释**：采用稠密向量检索，未接入混合检索或 rerank。来源与引用校验不能代替人工判断原文含义或经营因果。
- **任务恢复**：支持读取历史和继续人工等待中的研究；文档处理依赖进程内任务，进程异常退出后不自动续跑，运行中断的研究也不自动重发模型请求。
- **部署方式**：当前为本地单工作空间，未提供多人身份认证、生产级权限体系或分布式任务调度。
- **导出与离线阅读**：报告中的原应用 PDF 链接需要对应服务与原文件。静态演示保留历史导出，不能替代完整工作台中的重新校验。

# 功能状态与界面

当前版本提供本地单人财报研究工作台，包含企业与资料、三指标财务核对、跨年与同期分析、多文档问答、受控研究任务、PDF 证据查看和报告版本管理。

## 已有验证

历史交付已记录四份真实年报、十二项财务事实的本人核对与接受、三项真实经营研究、三份报告六个版本，以及指定版本下载和重启读取。新问答与经营解释的人工语义审阅仍有待完成，未将自动化通过视为全面业务认可。

本公开版以产品源码和可运行的基础验证为主，不分发历史运行数据库、原始 PDF、模型文件、凭据或完整内部验收档案。

## 当前限制

- 财务解析主要覆盖已验证的中文文本层年报版式；未声明任意扫描件或所有表格格式均可准确抽取。
- 当前使用本地单工作空间，没有多人身份与生产级权限体系。
- 模型解释、引用身份和人工语义结论是不同状态；合法引用不能自动证明经营因果。
- 静态演示只读取筛选后的历史内容；无法上传、重新问答或调用模型。
- 报告中的原应用 PDF 链接依赖对应服务与原文件，离线阅读不等于原文件已随包提供。

产品工作台保留 FinDoc Analyst 名称，公开项目和仓库使用 FinDoc Agent，突出其 RAG、工具调用与人工等待工作流。

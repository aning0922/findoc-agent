# 三条面试演示路线

以下是**讲解节奏5–10分钟**的可重复路线，自动脚本实际运行更快。使用本机14540、V3种子、模型disabled。展示真实公开PDF/程序计算/检索，不把历史归档、新模型解释和本人财务核准混在一起。登录凭据仅在被忽略的本机配置，不写在演示稿里。退出会恢复种子，下一人重新登录；开发者自己的原数据库不被覆盖。

## 路线一：从官方年报到可信数据（约6分钟）

1. 0:00–1:00 登录，展示首页Hero、3企业/5份完整年报和财务候选曲线。切营业收入/总资产，指出每点原PDF、实际期间、“预置候选·未核准”。首页任务/报告是当前种子或历史归档的只读统计。
2. 1:00–2:30 首页输入 `hezj` → 开始研究 → 搜索企业 → 手选600690/SSE → 2025中文年度全文。说明同时出现的港股/英文版不会被悄悄当作A股中文全文。点击确认下载并导入，等待资料就绪，再进入360。若官方接口限制，展示官网跳转/手动上传，不假称动态成功。
3. 2:30–4:30 企业与资料选择格力→三大报表，选择2025年报→提取三表候选。查看资产负债表的2025-12-31和利润/现金流的全年期间；选营业收入的2024比较期和2025本期。打开原PDF核对页码/单位。勾选显示待核对候选→生成趋势→企业概览，切折线/条形。
4. 4:30–6:00 选择当前期五项，生成三类财报体检，讲清程序规则与AI解释的边界。当前外部模型未验成功，保留未配置/待审状态；不点击“本人确认已逐项核对”。

真实证据：M5-official-reset、M1-M2-native、M3-http；新查询缓存身份修复d7b4160。只读查询原操作不会重新下载。退出后新generation仍命中公共PDF，但重新核验私有企业绑定。

## 路线二：从图表追问到原文和研究记忆（约5–7分钟）

1. 格力2025年报提取候选，明确选2024比较期与2025本期收入，生成趋势；点击2024点位。
2. 在研究助手点击“读取资料身份”，看到报告年2025、实际财务期间2024，服务端从不可变cell复验金额/版本/期间；不是信任浏览器传入金额。点击“建立混合检索索引”，完成后固定范围。
3. 输入“营业收入”并提交，显示真实PDF摘录。当前无模型时明确“模型未配置·展示真实检索原文”。点击定位原文，看精确quads高亮或明确降级原页；收藏一条证据。
4. 收藏改变记忆generation，主动重新固定研究范围，再在研究收藏中查询。展开跨会话记忆→显示全部，演示真实BGE召回；明确删除→确认删除，再查不再返回。
5. 可选OCR子路径：资料页选择“派生扫描示例”（旧legacyFAILED仍可见），执行真实Vision OCR，预览68行/54cell；在研究助手选OCR方式→读取资料身份→显式加入转录研究→建索引→固定范围→问题“2025上半年营业收入”→引用原PDF图像bbox。强调文件转录/身份未核验/财务未核准。

真实证据：M5-point-memory8检查、M1-M2-native21检查，provider0/人签0。收藏的引文身份及删除不复活已验；人工语义审读仍未执行。

## 路线三：双年研究、批量矩阵与可交付报告（约7–10分钟）

1. 格力360展开跨年经营变化，明确选择2024/2025两份报告，三个主题保持风险/主要业务/研发，点击开始对比。查看每主题双侧原文和各自PDF链接；没有检索到不能说该业务消失。当前不请求AI解释。
2. 主营业务结构选择格力2025→提取候选，查看产品/地区切换、环形图与收入表。分类总和不强行归一化，缺项/残差保留。
3. 研究助手展开批量研究→读取资料。选格力、美的，每家明确勾选2024、2025两份报告。准备2×2计划后暂停讲解：尚未执行；点击批准并开始，观察四格风险/跨年任务独立状态及引用。修复后真实socket基准119秒，全程纯工具，无新增LLM调用。UNKNOWN只查原操作，不自动重跑。
4. 同行候选对照：各企业2025三表提取，刷新进阶资料，选择同期间五指标、允许候选对照，生成并查看条形/原文。不能把用户手选企业写成已认证行业分类。
5. 我的报告选择刚保存的同行候选版本，勾CSV/XLSX/PPTX→生成导出。打开Excel/PPTX，浏览器打印版另存PDF。指出同domain/id/revision/完整SHA、原值Decimal文本、实际期间与候选状态。新版样例PDF2页，PPTX6页。下载不会再次调用模型或重新渲染。

模板加演：企业360展开研究模板，先选“年度经营概览”及来源→带入研究助手；再选“现金流质量”两份不同年份。按钮只准备草稿，进入研究页后仍须显式建索引/固定范围/提交。

## 失败处理和诚实表达

- 供应商4次ReadTimeout均保留UNKNOWN；没有新真实模型解释可展示，不用mock补上。深度Agent历史项目能力与本轮实际运行证据分开讲。
- 官方网站不可用→官网和手动上传；复杂表格unsupported→只展示支持范围；没有本人核准→候选路线继续。
- 研究或导出未知→查询原operation；不通过刷新/复制ID重发。父会话展示权限撤销后已生成文件也需重新鉴权。
- 截图/录屏见DELIVERY。自动浏览器操作不是用户本人财务签核，也不冒称真人已做可用性验收。

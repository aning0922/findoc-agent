# 三条面试演示路线

本机14540、V3 seed、当前模型配置已启用，共用原5元账本。以下是5–10分钟人工讲解节奏；自动录屏更短。财务候选、精确原文/OCR、程序规则、AI待审与本人确认分层。密码只从本机ignored配置查看。

## A · 官方资料到企业360（约6分钟）

1. 登录后看Hero/KPI、实际预置候选双年曲线和来源标注，搜索 `hezj`，明确选择600690/SSE与中文年度全文。
2. 明确下载并导入，说明官方网页adapter并非稳定API；受限就展示官方跳转/手动上传，不绕过限制。进入READY企业360。
3. 打开格力三表，显式选择2024/2025；展示2025报告的比较期与2024报告本期区别。查看物理PDF页、期间、单位、会计口径、合并范围。
4. 选本报告全年/年末核心五项，开启待核对候选观察，生成趋势。展示收入/净利/现金流/资产/负债率五KPI；切折线/柱状、资产负债率缺输入的明确空态。
5. 三规则体检分别展示程序观察、输入来源、公式/期间和下一问。本人未确认时保持候选；owner确认必须本人核对。

证据：M5-official-reset、M5-followup/profile-native与G1-G5-native。实际官方导入/跨查询新generation cache已跑，seed SHA保留。

## B · 双年Agent研究、版本报告与可删除记忆（约8–10分钟）

1. 研究助手明确选择格力2024/2025两份资料，分别进入综合研究、深度研究；输入同一问题“现金流风险还有哪些待核查？”。明确解析意图→核对计划/工具/角色/费用上界→批准原计划。
2. 看真实阶段事件：controller/supervisor、generalist或evidence/finance、tool/verifier。finance没有核准输入就说明不足，不能自己挑最新事实或核准金额。原文、推断、待核查问题分开。
3. 保存两个独立研究版本，比较同问题/同来源/同事实选择，不宣称多Agent必然更好。两年实际路线双方均有两份报告引用；固定E01-15单2025场景另存，不能混成同一次执行。
4. 报告中心选精确domain/id/revision，生成PPTX/Excel/CSV并打开打印版PDF；每次导出都绑定原SHA。图表复制已经保存draft rev1，重读仍绑定原cell记录。
5. 可从格力2025报告的2024比较期收入点进入原文/OCR研究：读取身份→显式建索引/固定范围→提交问题→定位同条引用。长表不能精确匹配时清楚显示原页回退，不假装精确高亮。收藏→新context→真实BGE召回→删除→再次查询不命中。

真实证据：interview-b-two-years及synthesis两份result、同题单2025原固定fixture、business native三份PPTX、point-memory-final。最后点图路径9检查PASS，实际location_mode=page_only。原AI现金流说明曾把年份/金额顺序写反，独立QA保留；新模板非数值解释合同隔离这类输出，不能展示旧错误为核对结论。

## C · 四模板、同行与可取消的批量研究（约7–9分钟）

1. 企业360打开研究模板：overview一份、cash同企业双年、peer明确两至三家公司各一份同年、changes同企业双年。每次核对来源/问题/模板版本，默认不请求AI；需要解释才勾选最多一次。
2. cash看两年实际现金流/利润候选及三规则；peer看真实公司名称/期间/同口径候选、未知口径不可比；changes看风险/业务/研发双侧原文，不把没搜到认定取消。
3. AI研究助手展开批量研究，手选格力/美的各两份。显式准备2×2计划，确认纯工具0调用或AI每格最多一次，批准后立即看到ACK与逐格状态。
4. 运行中取消只影响queued，active结果保留；来源失效一格不会抹掉另外三格。面试现场不需要故意损坏PDF，展示已保存的真实3AI返回+1missing-source UNKNOWN及恢复SHA凭证，说明Unknown只查不重发。
5. 展示业务结构/实际分部候选环形与原PDF、报告导出及退出完整seed恢复。跨代公开PDF可缓存，私有研究/上传/记忆不跨代，原账本不重置。

真实证据：四模板native子路径、batch-ai-controls 11检查、queued取消/文件故障原始10检查、实际业务图文件QA。所有说明与财务候选仍待人工审阅。

## 资产和失败边界

录屏逐文件SHA见recordings.json，原始webm保留本机ignored data，未公开上传；README不把本机地址伪装成线上演示。A/B/C原无模型演示与后续真实模型/文件/同图点补证按层级分别保存。旧selector/GET超时、输入预算拒绝、数值顺序错误和4条模型UNKNOWN均未抹掉。

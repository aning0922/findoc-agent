# C+ 页面与交互合同 · M0

Navy/Blue延续当前C视觉。工作包prototype是设计参照，正式实现不用iframe/内嵌静态HTML，也不导入其假金额。M0独立React可点击预览明确UI_MOCK；正式组件接服务端DTO与callbacks。

保留五个一级导航：首页／AI研究助手／企业与资料／研究任务／我的报告。企业详情二级tabs：360、三大表、体检、经营变化、同行、业务构成、资料。批量放AI助手，导出放报告详情。旧company overview/analysis/documents、conversation/task/report深链保留。

- 首页：~220–240px Hero+真实证券候选搜索，准确身份明确选择；四真实库存KPI，至少一图在1440x900首屏，最近研究与模板CTA。虚构图只在明确单独示意开关且虚构企业下，不绑定美的格力。
- 企业360：身份/代码/交易所/未知行业字段→五财务KPI(年份/单位/候选或核准)→营收趋势、净利/现金流比较、体检摘要→三表与双年变化/分部→文档/研究/报告证据。缺文档引导官方搜索或上传，候选和确认图层明显区分，不补零。
- 三表：年度/合并或母公司/单位选择、固定首列和内部横滚；行展示真实原值、时点/全年期间、状态、PDF证据drawer。一次同屏核对向导减少跳转，但确认/保存由本人明确执行。空值/unsupported给原因。
- 财报体检：收入利润分化/现金流质量/资产负债变化至少三卡，规则阈值/公式/输入可展开，候选卡标待核对，解释AI待审，缺值不可判定；追问只预填，不自动发模型。
- 双年变化：三主题左右双源原文+解释卡，新增/表述变化/共同延续/证据不足筛选。无命中不能讲取消业务；两PDF入口。
- 同行/业务结构：用户手选2–3证券主体，未知行业不认定；同期间口径不合给不可比；真实分类候选环图附subtotal/residual，不强制100%。
- 批次：组合预览列来源/格数/预算/人工依赖→明确批准→2x2独立状态和证据；取消未执行，不自动重发UNKNOWN。
- 报告导出：选确切revision，CSV/XLSX/PPTX/PDF有实际下载；候选/AI/来源脚注在文件中，不用“导出中”toast代替业务。
- 收藏/高亮：确认收藏source excerpt到现记忆；quads或OCR bbox精确定位，失败只页码+侧栏原文。跨会话查询/删除不复活。

状态均含idle/loading/empty/unsupported/failed/unknown/current/stale，长任务真实phase；高级hash/JSON折叠至详情。1440/1280/390实际浏览，390单列、table内部滚动、抽屉宽度受控，CTA可见。

# C+ 企业360 离线交互原型

直接双击打开 `index.html`，不需要 Node、网络、数据库或 API key。

- 点击侧边导航切换：首页总览、企业360、三大财务报表、财报体检、跨年度变化、同行对标、批量研究、报告与导出。
- 首页虚构趋势图支持选择营收/利润/现金流；三大报表可以切换。
- 企业搜索、体检、批量研究、导出按钮会显示明确的“尚待接入真实后端”的提示，不会暗中网络请求。
- 所有数值都是**虚构 UI_MOCK**，未使用真实上市公司名称绑定任何虚构财务金额，也不代表当前 FinDoc 已具有 C+ 功能。
- 用于 M0 讨论信息架构、风格和交互，不建议直接嵌入 React 正式前端。实际实现需要复用现有 `AppShell`/`DemoGate`/路由与后端。
- 推荐 1440px/390px 实际浏览后提出调整，并生成真实后端截图留存。

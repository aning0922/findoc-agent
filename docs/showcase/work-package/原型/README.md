# 离线首页 + 演示登录高保真交互原型

双击 `index.html`，无需 npm、后端和外部 CDN。

- 登录页面输入任意非空账号和密码，可进入 Dashboard。此页面**不实施真实身份验证**，属于设计验证 UI。
- 在登录页面点“模拟：另一位访客正在使用”，再提交，可以查看占用弹窗、申请接管、二次确认和重置后进入工作台的视觉流程。
- 进入首页后，可切换财务指标折线图，点击侧栏各页面，打开推荐问题，查看示例内容。
- 点击“模拟被接管”会返回登录页并展示下线提示；顶部显示 20 分钟模拟倒计时。
- 所有财务数字、公司名称、柱状/折线/环形图数据均为**虚构视觉示意**，不是实际年报或真实运行统计。
- “强制接管”是模拟动作。正式实现需要服务端 auth/session/generation/seed restore，详细见 `03_演示登录_独占接管_重置.md`。

Codex 将此原型用于风格和布局的起点；M0 可进行视觉优化，但不能降低功能范围、可访问性和数据真实性标识。

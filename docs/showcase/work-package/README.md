## 完成定义（求职作品，不是生产 SaaS）
- 有清楚、成熟的产品视觉和产品操作流程，尤其首页与登录冲突处理。
- 核心功能可真实操作、在固定演示数据上跑通；示例数据不可冒充真实财务或真人审批。
- 每个高级名词至少有一条真实技术路径：OCR 真调用、Agent 真交接、语义记忆真召回、PDF 真关联等。
- 初始演示状态可恢复、会话到期可回收、旧访客不能在接管后继续写新演示环境。
- 现有已验证财务事实/来源版本不因 UI 简化被破坏。
- 少量关键测试 + 3 条稳定面试脚本；留下已知问题清单。**不要求多租户、生产 SLO、企业权限、全量年报兼容**。

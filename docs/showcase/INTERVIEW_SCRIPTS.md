# 三条面试演示脚本 · C 候选

以下使用真实 React 页面和当前代服务。脚本是讲解路线；真实自动化覆盖与本人财务验收分别列明。官方目录限美的／格力2024／2025，日期和更正状态未知如实展示。历史／预置和新模型运行不可混称。示例输入不包含未核准金额。

## 1. 第一眼、资料与原文（约4分钟）

1. 打开 http://127.0.0.1:14530 ，在“欢迎体验 FinDoc”填写本机私有文件中的固定账户，点“进入演示”。等待恢复完成，先展示 Hero、2／3／2／2 库存和最近研究。指明示意财务曲线有水印；切换指标／图表可操作，不把它当成真实公司财务值。
2. 进入“企业与资料”，选择格力，查询2025官方目录，查看官方来源、未知披露日期／更正状态；若尚未导入，点“明确导入此年报”，等待真实 READY。种子已有版本就直接使用，不重复下载。演示手动上传回退入口。
3. 进入“AI 研究助手”，选格力2025年报并创建会话，在快速问答输入“摘录关于经营现金流变化的原文，并给物理页”。明确发送后查看回答与来源，打开原 PDF 指定物理页。证据不足则展示限制；不补造答案。
4. 只读刷新历史不会重新调用模型。进入“研究任务”或“我的报告”，打开预置案例并指出历史标记；历史完成不等于新任务执行或财务签核。

证据：官方导入和真实219页解析见 M2-disclosure；最终首页／登录／三宽见 M5/launcher-result.json。新问题实际发送需要合法模型配置和预算；历史浏览不需要新模型调用。旧快速问答合同回归与本轮综合研究真实调用分开记载。

## 2. OCR、财务候选与本人核对边界（约5分钟）

1. 在资料解析质量区域打开预置 OCR 样本，展示引擎、68行转录、54候选格和原页大图。说明这是美的2025物理第9页派生单页扫描，衍生PDF物理第1页，不是原生扫描公告。GET预览与刷新不再执行OCR；“明确开始新解析”才会新运行。
2. 对照 bbox／表格候选和原页，指出“需人工核对”。版式候选不能直接升级成已核准财务事实。
3. 打开扩展财务候选／review，说明总资产、总负债和来源。日期是实际2025-01-01／2025-12-31，不能把期初改称2024已确认事实。已核准图为空时保留缺口，示意图只用单独水印开关。
4. 如本人要现场完成旧财务核对，进入经营研究合法双年／双企业任务，由本人逐项核对原PDF、单位、期间、口径和固定六项，然后本人执行 ACCEPT、独立 SAVE、独立 RESUME。Agent 不代点；演示可停在“等待本人核对”，不影响其余研究功能展示。

证据：M2-ocr 真正执行 Apple Vision；M2-finance 实际HTTP候选与review；M4恢复OCR同artifact。**human_financial_approvals=0**，核准图／比率正向仅fake fixture，不说已真人验收。

## 3. 真实研究分工、报告与记忆（约6分钟）

1. 同一冻结格力2025资料会话，选择“综合研究”，输入“请根据格力2025年报总结主要经营风险，只要原文与解释，不要计算”。点击“明确解析意图”；如模型提案不合法会明确回退规则，先核对范围，再点“明确准备研究计划”。
2. 阅读计划、工具和预算，勾选“我已阅读并确认此计划”，点“确认并开始研究”。看真实阶段事件／用量，完成后阅读综合解释、待核查问题，展开原文证据并打开物理页。
3. 对同一问题选择“深度研究”，再次明确意图与计划并批准。展示 Evidence 和 RiskOperations 的真实工具调用／交接／汇合与程序 verifier；对比调用次数与覆盖，不预设多Agent更好。只读刷新或深链不会重新批准执行。
4. 在研究结果中“准备报告草稿”，填写标题和备注、“明确创建报告”，打开报告版本；在“我的报告”保存新版、查看旧版，点“打开打印页 / 保存 PDF”。在浏览器实际保存并打开文件后再称导出成功。历史来源复核、AI解释待审、无财务确认章节均保留。
5. 打开“研究记忆与偏好”，明确确认保存现金流待查笔记，另建会话换词查询“现金回收和盈利质量”，查看真实BGE语义召回；二次确认删除后再次检索不再召回。研究笔记不成为财务事实。明确保存指标／单位／研究习惯偏好后回首页查看实际变化。
6. 若演示接管，第二个独立浏览器登录观察占用和剩余时间。默认wait_only；仅已明确启动owner模式时，由本人输入独立owner密码、二次确认。旧浏览器下线，新代恢复全部种子，新增笔记等消失。不要把公开访客当owner。

证据：M5/06nyuff2 实际UI单4model/2tools、双7/4、报告v1/v2与5页PDF、真实录屏；M3-memory 跨会话换词召回／删除及偏好；M4/full-reset 两独立Chromium进程与真实HTTP完整恢复。真人现场讲解仍由本人进行，本记录不冒充真人走查或财务确认。
